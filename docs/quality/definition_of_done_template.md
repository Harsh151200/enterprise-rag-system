# Definition of Done Template

Work Item:  
Owner:  
Reviewer:  

## Functional Completion
- [ ] Acceptance criteria met.
- [ ] Required edge cases handled.
- [ ] Backward compatibility validated (or breaking change documented).

## Engineering Quality
- [ ] Code is readable and maintainable.
- [ ] Existing architecture and conventions followed.
- [ ] Error handling and logging are adequate.

## Verification
- [ ] Relevant lint/build/test checks passed.
- [ ] Manual verification completed where required.
- [ ] No regression introduced in related flows.

## Security and Compliance
- [ ] Security-sensitive paths reviewed.
- [ ] Secrets and credentials are not hardcoded.
- [ ] Data handling complies with project policy.

## Documentation
- [ ] User-facing or developer documentation updated.
- [ ] Operational notes/runbooks updated if behavior changed.
- [ ] Changelog entry included when release-impacting.

## Ready to Merge/Release
- [ ] Reviewer approval complete.
- [ ] Follow-up items tracked outside this deliverable.
