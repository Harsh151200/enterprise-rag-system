# Release Checklist Template

Release Version:  
Target Date:  
Release Owner:  

## 1. Scope and Planning
- [ ] Version selected using SemVer policy.
- [ ] Scope locked and approved.
- [ ] Risk and rollback plan reviewed.

## 2. Quality Gates
- [ ] Lint/build/test checks passed.
- [ ] Security checks passed.
- [ ] Dependency and configuration changes reviewed.
- [ ] Performance and reliability criteria met.

## 3. Documentation and Communication
- [ ] Changelog updated.
- [ ] Release notes prepared.
- [ ] Operational runbook updates completed.
- [ ] Stakeholders notified of release window.

## 4. Deployment Readiness
- [ ] Environment configuration validated.
- [ ] Secrets and credentials verified.
- [ ] Migration and data impact reviewed.
- [ ] Monitoring and alerting checks prepared.

## 5. Go/No-Go
- [ ] Definition of Done satisfied.
- [ ] Final approver sign-off recorded.
- [ ] Go decision documented.

## 6. Post-release Verification
- [ ] Smoke checks completed.
- [ ] Core API and ingestion workflow verified.
- [ ] Incident watch period completed.
- [ ] Release closed and archived.
